# Security Log Analyzer & Brute-Force Detector

A beginner-friendly cybersecurity project built with Python to analyze
authentication logs and identify suspicious login activity.

## Features

- Analyze authentication logs
- Detect failed login attempts
- Identify possible brute-force attacks
- Extract suspicious IP addresses
- Generate security reports
- Unit testing

## Technologies

- Python
- Regular Expressions
- CSV
- Linux Security Logs
- GitHub

## How It Works

Authentication Log
        ↓
Log Parsing
        ↓
Failed Login Detection
        ↓
IP Address Analysis
        ↓
Brute-Force Detection
        ↓
Security Report

## Project Structure

- `main.py` - Runs the application
- `parser.py` - Reads and processes log data
- `detector.py` - Detects suspicious login activity
- `report.py` - Generates reports
- `test_detector.py` - Tests detection functionality
